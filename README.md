# 🛒 Telegram-бот для продажи VPN-подписок (Remnawave)

Готовый магазин подписок в Telegram, интегрированный с панелью [Remnawave](https://remna.st).
Пользователь платит — бот сам создаёт/продлевает ему аккаунт в Remnawave и выдаёт ссылку на подписку + QR-код.

## ✨ Возможности

**Для покупателей:**
- 🛍 Покупка подписки в пару кликов, доступ выдаётся **автоматически** сразу после оплаты
- 🏦 **Перевод на вашу карту**: реквизиты показывает бот, оплату подтверждает админ по чеку в один тап
- 💳 **ЮKassa** — автоматический приём карт (опционально); Stars/крипта — выключены, включаются в админке
- 🎫 **Промокоды**: активация в боте, дни подписки начисляются автоматически
- 🎁 **Пробный период: 1 день сразу + 2 дня за подписку на канал** — воронка прогрева канала, лимит 15 ГБ
- 👥 **Партнёрская программа**: своя ссылка у каждого, бонусные дни за друга с первой оплатой
- 🆘 **Поддержка — тикеты прямо в боте**: переписка с админом, кнопка «Вопрос решён»
- ❓ **FAQ** в боте — ответы на типовые вопросы без обращения в поддержку
- ⏳ **Напоминание о брошенной оплате** — через час бот сам вернёт покупателя к реквизитам
- ❌ **Отклонение чека с причиной** — «неверная сумма», «чек не читается», «платёж не найден» или свой текст
- 💳 «Моя подписка»: срок действия, трафик, ссылка, QR-код
- 📖 Инструкция по подключению (iOS/Android/Windows/macOS/TV)
- ⏳ Напоминания об окончании подписки (за 3 дня, за 1 день и в день истечения)
- 🔄 Повторная покупка **продлевает** текущую подписку (плюс остаток дней), опционально сбрасывает трафик

**Для администратора (`/admin`):**
- 📊 Статистика: продажи по способам оплаты, за 7/30 дней, пользователи бота и панели
- 📡 Состояние нод Remnawave (онлайн/оффлайн)
- 🔧 Проверка панели (токен, squads, платёжки) прямо из бота
- 📢 Массовая рассылка всем пользователям бота
- 🎁 Выдача/продление подписки вручную (по TG ID или логину Remnawave)
- 🚫 Отключение и ✅ включение пользователей
- 📢 **Рассылки по сегментам**: все / подписка истекает ≤3 дней / без активной подписки / ни одной оплаты / платившие
- 🎫 **Промокоды**: создание (код, дни, лимит, срок), вкл/выкл, статистика активаций
- 🔗 **Рекламные ссылки** (`?start=ref_имя`): переходы, оплаты и выручка по каждой кампании
- 🎁 **Пробный период**: вкл/выкл, срок, канал и ссылка — прямо из бота
- 💳 **Переключатели способов оплаты** — без правки .env и перезапуска
- 👤 **Карточка пользователя**: поиск по TG ID/логину — подписка, платежи, источник рекламы,
  рефералы + кнопки «продлить»/«вкл-выкл»
- 🎫 **Обращения из поддержки**: список, ответ (текст/фото/файл) пользователю, закрытие
- 📊 **Воронка по рекламным ссылкам**: юзеры → оплаты → конверсия % → выручка
- 📤 **Экспорт**: полный отчёт Excel с графиками + CSV платежей и пользователей
- 🔔 **Уведомления админам**: каждая оплата, каждый новый пользователь, реферальные бонусы
- 🔔 **Отчёт каждые 4 часа**: продажи и выручка за период, новые юзеры, статус нод
- 🔴 **Алерты о нодах**: мгновенное сообщение, когда нода ушла в оффлайн и когда вернулась
- 👥 **Операторы оплаты**: добавьте помощников — им приходят чеки, они подтверждают/отклоняют оплаты (без доступа к остальной админке)
- 💼 **Редактор тарифов**: создание/изменение цены, срока, названия, описания, скрытие тарифа — прямо из админки, без перезапуска
- 📡 **Загрузка нод**: онлайн-пользователи и CPU (если панель отдаёт) прямо в экране «📡 Ноды»
- 🏷 Хэштеги в уведомлениях: `#оплата` на чеки/подтверждения, `#покупка` на продажи — удобно искать в истории чата
- 📢 **Системный канал**: дублирует все события с хэштегами (`#пользователь #оплата #покупка #промокод #пробный #реферал #админ #тикет #нода #бэкап #отчёт #ошибка`) — журнал всего магазина, доступный поиском Telegram
- 💾 **Бэкап БД файлом в Telegram** — копия данных у вас в чате, вне сервера
- 📊 **Полный отчёт Excel**: сводка с графиками оплат и выручки по дням, листы платежей/юзеров/рекламы
- 📈 **Недельный Excel-отчёт автоматически** — приходит админам каждую неделю
- 💾 **Автобэкап БД** раз в сутки в `data/backups/` (хранятся 7 копий)
- ⚠️ Уведомления об ошибках выдачи

## 🚀 Быстрый старт

### 1. Подготовьте Remnawave
1. В панели: **Настройки → API Tokens** → создайте токен.
2. **Управление → Internal Squads** → убедитесь, что есть squad с вашими хостами → скопируйте его **UUID**.
3. (Опционально) Проверьте, что ссылка на подписку открывается из панели — бот отдаёт пользователю ту же ссылку.

### 2. Создайте бота
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Узнайте свой Telegram ID (например, [@userinfobot](https://t.me/userinfobot)) — он понадобится для админки.

### 3. Настройте и запустите

```bash
git clone <repo> vpn-bot && cd vpn-bot
cp .env.example .env
nano .env        # заполните BOT_TOKEN, ADMIN_IDS, REMNAWAVE_*, платёжки
```

Минимальный `.env`:

```env
BOT_TOKEN=123456:AAF...
ADMIN_IDS=123456789
REMNAWAVE_PANEL_URL=https://panel.example.com
REMNAWAVE_API_TOKEN=eyJhbGciOi...
REMNAWAVE_SQUAD_UUID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

Проверьте окружение (панель, токены, ноды, squads):

```bash
python3 -m bot.doctor
```

Запуск:

- **Через Docker (рекомендуется):**
  ```bash
  docker compose up -d --build
  docker compose logs -f
  ```
- **Либо напрямую:**
  ```bash
  pip install -r requirements.txt
  python3 -m bot
  ```

## 🖥 Деплой на хост с Remnawave

Самый удобный вариант: бот ходит в панель **напрямую по внутренней docker-сети**
(`http://remnawave:3000`) — быстрее, не зависит от DNS/TLS публичного домена и работает
даже если порт панели закрыт файрволом. Наружу бот ничего не публикует (портов в compose нет) —
только исходящие соединения к Telegram и платёжным системам.

### Шаг 1. Скопируйте код на сервер

```bash
# если PR ещё не смержен — клонируйте ветку:
git clone -b arena/01a0440c-bot https://github.com/pavel-ygo/bot.git /opt/vpn-bot
# после мержа:
git clone https://github.com/pavel-ygo/bot.git /opt/vpn-bot
cd /opt/vpn-bot
```

### Шаг 2. Узнайте имя docker-сети и контейнера панели

```bash
docker network ls | grep -i remna        # обычно: remnawave_network
docker ps --format '{{.Names}}' | grep -i remna   # обычно: remnawave
```

В стандартной установке Remnawave это `remnawave_network` и `remnawave` — они уже
подставлены по умолчанию, ничего менять не нужно.

### Шаг 3. Настройте .env

```bash
cp .env.example .env
nano .env
```

Ключевые строки для совместного хоста:

```env
REMNAWAVE_PANEL_URL=http://remnawave:3000     # контейнер панели напрямую
REMNAWAVE_API_TOKEN=...                       # панель → Настройки → API Tokens
REMNAWAVE_SQUAD_UUID=...                      # панель → Internal Squads
# в конце файла раскомментируйте две строки:
COMPOSE_FILE=docker-compose.yml:docker-compose.remna.yml
REMNAWAVE_DOCKER_NETWORK=remnawave_network
```

> Если сеть панели называется иначе — впишите её в `REMNAWAVE_DOCKER_NETWORK`.

### Шаг 4. Проверьте и запустите

```bash
docker compose run --rm vpn-bot python -m bot.doctor   # связь с панелью, ноды, squads
docker compose up -d --build
docker compose logs -f                                  # смотреть логи
```

`doctor` покажет ноды (обе ваши должны быть `online`), найденные Internal Squads
и подскажет, если `REMNAWAVE_SQUAD_UUID` не совпадает с панелью.

### Обновление бота

```bash
cd /opt/vpn-bot && git pull && docker compose up -d --build
```

### Альтернатива

Не хотите трогать docker-сеть панели — просто оставьте
`REMNAWAVE_PANEL_URL=https://panel.example.com` (публичный адрес) и запускайте
обычный `docker compose up -d --build` без файла `docker-compose.remna.yml`.
Работает так же, трафик пойдёт через Caddy.

## 💰 Приём платежей

**По умолчанию включён только 🏦 перевод на карту/СБП** — для него не нужны ни ИП,
ни самозанятость, ни договоры с сервисами: деньги приходят сразу на вашу личную карту.
⭐ Stars, 🪙 крипта и 💳 ЮKassa выключены по умолчанию и включаются в
`/admin → 💳 Способы оплаты` (ЮKassa доступна только ИП/самозанятым/юрлицам).

### 🏦 Перевод на карту (основной способ)

**Несколько карт:** `/admin → 🏦 Оплата на карту → ➕ Добавить карту` — добавьте
карты разных банков (Сбер, Т-Банк, Альфа…) и телефон СБП. Покупатель сам выбирает
удобный банк — перевод внутри одного банка мгновенный и без комиссии/лимитов.
Карты можно включать/выключать и удалять; последнюю включённую бот защищает.

**Умная сумма (анти-фрод):** к цене заказа добавляется случайная скидка
**до 10 ₽** (для тарифа 199 ₽ покупатель платит 189–199 ₽ целыми рублями) —
персональная метка платежа. Вы сверяете поступление за секунды, а в режиме
автоподтверждения это доп. фильтр скама. Отключается кнопкой «⚙️ Умная сумма».

Поток: покупатель выбирает карту → видит реквизиты и сумму с копейками →
переводит → «✅ Я оплатил(а)» → скриншот → подтверждение → подписка выдана.
Никаких сервисов и комиссий — деньги сразу на ваши карты.

### 💳 ЮKassa (опционально, требует статуса)

`YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET` из личного кабинета — подключение возможно
только для ИП, самозанятых или юрлиц. Если у вас нет такого статуса — просто не
заполняйте реквизиты: способ останется скрытым. Оплата через ЮKassa подтверждается
автоматически.

### ⭐ Telegram Stars / 🪙 CryptoBot (опционально)

Встроены, но по умолчанию выключены. Stars включаются тумблером в админке;
для CryptoBot заполните `CRYPTOBOT_TOKEN` (там же включается тумблером).

Счёты ЮKassa/CryptoBot ждут оплаты 24 часа и затем отменяются автоматически.

## 🧾 Тарифы

Тарифы задаются JSON-ом в `.env` (переменная `TARIFFS`). Пример с несколькими тарифами:

```json
{
  "m1":   {"title": "1 месяц",  "days": 30,  "price_rub": 199, "price_stars": 150, "price_usdt": 1.99,  "description": "Все локации"},
  "m3":   {"title": "3 месяца", "days": 90,  "price_rub": 499, "price_stars": 400, "price_usdt": 4.99,  "description": "Выгода 17%"},
  "m12":  {"title": "12 месяцев","days": 365,"price_rub": 1499,"price_stars": 1400,"price_usdt": 14.99, "description": "Выгода 38%"}
}
```

- Не нужен какой-то способ оплаты — поставьте `null` вместо цены.
- Telegram Stars: 1 ⭐ ≈ минимальная цена 1 звезда; ЮKassa — рубли; CryptoBot — USDT.

## 🎫 Промокоды, реклама и пробный период (админка)

**Промокоды** (`/admin → 🎫 Промокоды`): создаёте код (например `WELCOME`), указываете
сколько дней подписки он даёт, лимит активаций и срок действия. Пользователь вводит код
в боте («🎫 Промокод») — дни начисляются к его подписке автоматически. Один код можно
активировать один раз на человека; лимит и срок проверяются сами.

**Рекламные ссылки** (`/admin → 🔗 Рекламные ссылки`): под каждую рекламную площадку
создаётся ссылка вида `https://t.me/ваш_бот?start=ref_youtube`. В статистике кампании —
количество пришедших пользователей, оплат и выручка. Источник фиксируется при первом
запуске бота и прикрепляется ко всем последующим оплатам пользователя.

**Пробный период** (`/admin → 🎁 Пробный период`) — двухступенчатый:
1. Юзер сразу получает **базовые дни** (по умолчанию 1) — без условий, без карты.
2. Если задан канал — кнопка **«+2 дня за подписку»**: бот проверяет подписку через
`getChatMember` и начисляет бонус. Канал растёт, юзер дольше остаётся в продукте.

Лимит трафика триала (по умолчанию 15 ГБ), базовые дни и бонус — настраиваются
прямо в админке. Канал пуст → бонус выключается, триал выдаётся просто так.

### 📇 Карточка пользователя в панели Remnawave

Бот заполняет карточку каждого клиента, и она обновляется при каждой оплате:

- **Email** — Telegram-username клиента (`@username`, или `id123` если username нет)
- **Tag** — сегмент: `tgbot|paid` / `tgbot|trial` / `tgbot|promo` / `tgbot|gift` / `tgbot|refbonus`
- **Description** — мини-история: `Источник: youtube | Покупок: 3 (597 ₽) | Оплата 29.08.2026`
  (для проб/промо/подарков — соответствующая пометка)

Если панель отклонит доп. поля — бот автоматически повторит создание с урезанным
payload, выдача подписки не сломается.

**Поддержка-тикеты**: пользователь жмёт «🆘 Поддержка», описывает проблему — сообщение
приходит админам с кнопками «💬 Ответить» / «✅ Закрыть». Ответ (текст, фото, файл) бот
доставляет пользователю. Пока обращение открыто, любые сообщения пользователя в чат
тоже попадают к админам. Кнопка «FAQ» в меню отвечает на типовые вопросы.

**Партнёрская программа**: у каждого пользователя ссылка
`https://t.me/бот?start=u<его_id>` (кнопка «👥 Друзья» → «Поделиться»). Если
приглашённый впервые оплачивает подписку — рефереру автоматически начисляется
`REF_BONUS_DAYS` дней (по умолчанию 3) и приходит уведомление.

### 🎨 Страница подписок (опционально, настройка на сервере)

Официальная веб-страница Remnawave Subscription Page: клиент по ссылке видит страницу
с кнопками приложений и автоустановкой конфига. Пошаговая инструкция:
**[docs/SUBSCRIPTION_PAGE.md](docs/SUBSCRIPTION_PAGE.md)**. После настройки добавьте
`SUB_PAGE_DOMAIN=https://sub.ваш-домен` в `.env` — бот начнёт выдавать красивые ссылки
(приоритет над ссылками панели уже встроен).

**Системный канал** (`/admin → 📢 Системный канал`): создайте приватный канал,
добавьте бота администратором с правом публикации, пришлите боту ID канала
(добавьте канал в бота → переслать сообщение из канала @userinfobot, чтобы узнать ID).
Всё событие попадает в канал: новые юзеры, оплаты, чеки и решения по ним, промокоды,
реферальные бонусы, выдачи админом, тикеты, состояние нод, бэкапы, отчёты, ошибки.
Подтверждение оплат по-прежнему происходит кнопками в боте — канал только журнал.

**Отчёты и алерты** (`/admin → 🔔 Отчёты и алерты`): каждые 4 часа бот присылает
сводку (оплаты, выручка, новые юзеры, статус нод); при уходе ноды в оффлайн —
мгновенный алерт 🟢/🔴; ежедневный бэкап БД дублируется файлом в чат с админом.
Каждый пункт включается/выключается отдельно.

**Автобэкап**: раз в сутки SQLite копируется в `data/backups/bot-ДДДДММДД-ЧЧММ.db`
(хранятся 7 копий) и отправляется админам в Telegram. Восстановление: остановить бота,
заменить `data/bot.db` копией, запустить.

Все настройки админки живут в SQLite и меняются на ходу — перезапуск бота не нужен.

## 🧩 Как это работает

```
Пользователь            Бот                        Remnawave            Платёжка
     │  /start           │                             │                  │
     │  Купить ─────────►│                             │                  │
     │  Оплата ──────────┼─── счёт/инвойс ────────────┼─────────────────►│
     │                   │◄── подтверждение оплаты ────┼──────────────────┤
     │                   ├─── создать/продлить юзера ─►│                  │
     │◄── ссылка + QR ───┤◄── subscriptionUrl ─────────┤                  │
```

- Пользователь бота связывается с пользователем Remnawave по `telegramId` — повторная
  покупка всегда продлевает существующий аккаунт и включает его заново.
- Все операции идемпотентны: двойное подтверждение оплаты не выдаст две подписки.
- Напоминания и продления не ломают счётчик уведомлений (хранится в SQLite).

## ❓ FAQ

**Бот пишет, что токен бота неверный.** — Все настройки лежат в файле **`.env` в корне
проекта** — рядом с `docker-compose.yml` (создаётся из шаблона: `cp .env.example .env`).
Найти папку запущенного проекта на сервере:

```bash
docker compose ls        # покажет путь к compose-файлам всех запущенных проектов
```

Проверьте строку `BOT_TOKEN=` — токен должен быть целиком, вида `123456789:AA...`
(без кавычек, пробелов и `bot` в начале). Проверить токен с сервера:

```bash
curl -s https://api.telegram.org/bot<ТОКЕН>/getMe
```

После правки `.env` пересоздайте контейнер (именно `up -d`, а не `restart` —
иначе новые переменные не подхватятся):

```bash
docker compose up -d && docker compose logs -f
```

**В логах `TelegramConflictError: Conflict: terminated by other getUpdates request`.** —
Где-то запущен второй экземпляр бота с тем же токеном (другой контейнер, второй сервер,
запуск вручную в screen/tmux). Найдите и остановите его:

```bash
docker ps -a --format '{{.Names}}\t{{.Image}}\t{{.Status}}'   # лишние контейнеры
ps aux | grep -iE 'python.*(bot|aiogram)' | grep -v grep       # процессы на хосте
```

Не нашли — отзовите токен: @BotFather → /mybots → API Token → Revoke, впишите новый
в `.env` и выполните `docker compose up -d`. Все посторонние копии остановятся сами.

**Кнопка настройки карты «не отвечает» / ввод «завис».** — Отправьте боту `/cancel`
и зайдите заново: `/admin → 🏦 Оплата на карту`. Номер карты можно присылать в любом
виде — с пробелами, дефисами; бот сам уберёт лишнее и отформатирует. Выход из режима
ввода — `/cancel` или кнопка «⬅️ В админку».

**Бот пишет «Панель недоступна».** — Проверьте `REMNAWAVE_PANEL_URL` (доступен ли он с
сервера, где запущен бот) и не истёк ли `REMNAWAVE_API_TOKEN`.

**Пользователь оплатил, но подписка не пришла.** — Смотрите `/admin → 📊 Статистика` и
логи: при ошибке выдачи админам приходит уведомление, платёж помечается `error` и
пользователю обещают разбор. После исправления выдайте подписку вручную
(`/admin → 🎁 Выдать подписку`).

**Как поменять тексты бота?** — Все строки в `bot/texts.py`.

**Где хранятся данные?** — SQLite-файл `data/bot.db` (пользователи бота, платежи).
Сами подписки живут в Remnawave, бот их только создаёт/продлевает.
